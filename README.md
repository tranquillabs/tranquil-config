# Tranquil Config

**Sensible defaults, settings, and the Tranquil settings tab for [Tranquil Studio](https://github.com/tranquillabs/tranquil-client).**

> Part of the Tranquil toolkit, in early developer preview.

## What it does

- Ships Tranquil's default settings — a focused tree view, most-recently-used command-palette ordering, and other sane defaults.
- Adds the first-class **Tranquil settings tab** with a live UI-theme picker.
- Wires up local configuration and secrets.
